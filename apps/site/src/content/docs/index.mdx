## From sign-in to messages

```ts
import { InboxLink } from "@inboxlink/sdk";

const il = new InboxLink({ apiSecret: process.env.INBOXLINK_API_SECRET });

// 1. Send the person to InboxLink's Connect page
const { connectUrl } = await il.createConnectSession({
  externalUserId: user.id,
  redirectUri: "https://your-app.example.com/inboxlink/done",
});

// 2. When they come back, swap the one-time token for a grant
const { grantId } = await il.completeConnect({ redirectUrl: request.url });

// 3. Read their mail
const page = await il.messages.list(grantId, { limit: 25 });
```

## How it works

<Steps>

1. **Your server creates a Connect session** and sends the person to the `connectUrl` it returns.

2. **InboxLink runs Google sign-in** with PKCE on its own Google client. Your app never registers a Google OAuth client and never sees a Google token.

3. **The refresh token goes into the vault**, encrypted with AES-256-GCM. The person comes back to your `redirectUri` with a one-time `public_token`.

4. **Your server exchanges it for a `grantId`**, the only thing you store.

5. **You call the messages API with the grant**: list, get, sync, and signed webhooks when new mail or a sync arrives.

</Steps>

## Why use it

<CardGrid>
  <Card title="Tokens stay out of your app" icon="seti:lock">
    Only InboxLink's vault holds refresh tokens. Revoking a grant deletes the
    sealed token. A breach of your database leaks grant ids, not mailbox access.
  </Card>
  <Card title="Fails closed" icon="warning">
    When Google withdraws access the grant turns `needs_reauth` and reads stop.
    Temporary Google or network errors leave the grant active and retry on the
    next sync.
  </Card>
  <Card title="One normalized API" icon="document">
    Cursor-paged lists, full message bodies with attachment metadata, a synced
    cache by default and live Gmail search when you ask for it.
  </Card>
  <Card title="Open source" icon="github">
    MIT licensed TypeScript. Use the hosted service or run your own on Vercel
    and Postgres.
  </Card>
</CardGrid>

| | |
|---|---|
| **Gmail** | Available: Connect, message list and get, history sync, Gmail push, signed webhooks |
| **SDK** | [`@inboxlink/sdk`](https://www.npmjs.com/package/@inboxlink/sdk) on npm, published with provenance |
