# `@inboxlink/core`

Shared TypeScript types, normalized mailbox models, adapter interfaces, and vault crypto helpers for [InboxLink](https://github.com/EtienneFokou-E18560/inboxlink).

Published alongside `@inboxlink/sdk` (the SDK depends on this package). Host apps that only need types can import from `@inboxlink/core` directly.

See [CHANGELOG.md](./CHANGELOG.md) for release notes.
